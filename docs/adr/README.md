# Architecture Decision Records

Decisions that amend or refine `docs/project-definition.md`. A later ADR wins over the project definition where they conflict.

**An ADR is required for:** changes to `CLAUDE.md` (studio doctrine), glossary terms, artifact schemas after M1, and pinning or changing the Blender version.

Files are `NNNN-slug.md`, numbered in order. Copy `0000-template.md` to start one.
